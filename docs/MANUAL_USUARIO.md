# Manual de usuario de Hemeroteca 2.2.15

Abre [Guía de instalación y uso por perfil](GUIA_POR_PERFILES.html). Funciona sin Internet e incluye instalación, usuario regular, administrador regular, administrador maestro, permisos, catálogo, recuperación, PDF, respaldos, red y mantenimiento.

Esta guía sustituye las instrucciones antiguas de preparación y registro. El instalador incluye todo lo necesario. Todos los periódicos admiten fechas entre 1970 y 2100.
