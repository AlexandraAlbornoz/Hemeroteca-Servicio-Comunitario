# Seguridad

No publique contraseñas, claves, respaldos, bases reales ni datos personales en
issues o pull requests. Para reportar una vulnerabilidad, use el reporte privado
de vulnerabilidades del repositorio si el mantenedor lo ha habilitado. Si no está
habilitado, solicite un canal privado sin describir públicamente la explotación.
El mantenedor debe habilitar ese canal antes de recibir reportes de seguridad.

La configuración técnica, comandos de auditoría, protección de datos locales y
activación de reglas en GitHub están en [docs/seguridad.md](docs/seguridad.md).
No se ha habilitado un canal remoto ni protección de ramas desde esta carpeta.

Al reportar, indique versión, pasos mínimos, impacto y un ejemplo con datos
ficticios. No adjunte bases, credenciales, códigos de recuperación o claves TLS.
No se promete un plazo de respuesta ni mantenimiento de versiones anteriores;
el mantenedor debe definirlos al publicar el repositorio.
